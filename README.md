# 🏥 Healthcare and Engineering: A Deep Dive in Human Technology
# 1. Εισαγωγή

Το workshop αυτό έχει ως σκοπό τη διδαχή των βιοαισθητήρων, της βιοϊατρικής οργανολογίας και της εφαρμογής της τεχνολογίας στην παροχή υπηρεσιών υγείας.

Το πρακτικό μέρος εστιάζει στη δημιουργία ενός ψηφιακού συστήματος παρακολούθησης θερμοκρασίας, προσομοιώνοντας ένα πραγματικό νοσοκομειακό περιβάλλον. Οι συμμετέχοντες θα μάθουν πώς να μετατρέπουν αναλογικά σήματα από το ανθρώπινο σώμα σε ψηφιακή πληροφορία διαθέσιμη σε ένα κεντρικό δίκτυο (Server).
# 2. Υλικό 

   - Επεξεργασία & Δίκτυο:

        - [ ] ESP32 C3: (Ή οποιοσδήποτε μικροελεγκτής με WiFi & ADC).

        - [ ] Raspberry Pi 5: Λειτουργεί ως ο κεντρικός Server του συστήματος.

   - Αισθητήρες & Αναλογικά Στοιχεία:

        - [ ] LM35: Αναλογικός αισθητήρας θερμοκρασίας ακριβείας (10mV/∘C).

        - [ ] LM358: Τελεστικός Ενισχυτής (Op-Amp) για τη βελτίωση του σήματος.

        - [ ] Ποτενσιόμετρο: Για τη ρύθμιση του ορίου αναφοράς ή του κέρδους.

   - Παθητικά Στοιχεία & Ενδείξεις:

        - [ ] Red LED: Οπτική ένδειξη συναγερμού.

        - [ ] Αντιστάσεις:

        - 220Ω (για το LED).

        - 4.7kΩ (Rf​) & 1kΩ (Ri​) για τη ρύθμιση του κέρδους (Gain).

    
>  οι δύο προηγούμενες αντιστάσεις υπολογίστηκαν με βάση τον παρακάτω τύπο: 
>   Gain = Rf/Ri 
>   και με τη χρήση του [datasheet του lm35](https://www.ti.com/lit/ds/symlink/lm35.pdf) (Vout = 1mV*°C).
>   !Να κάνετε τον υπολογισμό με βάση τις αντοχές του δικού σας μικροεπεξεργαστή!

# 3. Λογισμικό (Software Stack)

   Arduino IDE: Για τον προγραμματισμό του ESP32 και την αποστολή δεδομένων μέσω πρωτοκόλλου MQTT.

   Node-RED: Η «καρδιά» του Server. Χρησιμοποιείται για:

   -Την επεξεργασία των δεδομένων (Flows).

   -Tην απεικόνιση σε Dashboard (Dashboard 2.0).

   -Τη διαχείριση ειδοποιήσεων (Smart Alerts).

# 4. Εγκατάσταση & Ρύθμιση
Α. Προετοιμασία Node-RED

   Εγκατάσταση Παλετών: Από το μενού Manage Palette, εγκαταστήστε το @flowfuse/node-red-dashboard.

   Εισαγωγή Flow:

   - Αντιγράψτε τον κώδικα από το αρχείο flows.json.

   - Στο Node-RED, επιλέξτε Import και επικολλήστε τον κώδικα.

   - Ρυθμίστε το MQTT-Broker node στη διεύθυνση IP του Raspberry Pi σας.

Β. Προετοιμασία ESP32

   - Εγκαταστήστε τις βιβλιοθήκες WiFi.h και PubSubClient.h στο Arduino IDE.

   - Ανεβάστε τον κώδικα, βεβαιώνοντας ότι το Topic στο MQTT συμπίπτει με αυτό του Node-RED (π.χ. monitor/sensor1).

# 5. Λειτουργία του Συστήματος

Το σύστημα ακολουθεί τα 5 βήματα ενός ιατρικού monitor:

   1. Συλλογή: Ο LM35 ανιχνεύει τη θερμοκρασία.

   2. Ενίσχυση: Ο LM358 προετοιμάζει το σήμα για τον ADC.

   3. Επεξεργασία: Ο ESP32 ψηφιοποιεί και στέλνει την τιμή μέσω WiFi.

   4. Απεικόνιση: Το Node-RED εμφανίζει το γράφημα στο Dashboard.

   5. Συναγερμός: Αν η τιμή βγει εκτός ορίων (36∘C−39∘C), ενεργοποιείται οπτική και ψηφιακή ειδοποίηση.
