# 🏥 Health Monitor Project (ESP32 & Node-RED)

Ένα ολοκληρωμένο σύστημα παρακολούθησης θερμοκρασίας ασθενών σε πραγματικό χρόνο, σχεδιασμένο για νοσοκομειακή χρήση.

## 🚀 Πώς να το χρησιμοποιήσετε (Installation)

Για να τρέξετε αυτό το project στο δικό σας Node-RED, ακολουθήστε αυτά τα βήματα:

1. **Εγκατάσταση Απαραίτητων Nodes:**
   Πριν την εισαγωγή, βεβαιωθείτε ότι έχετε εγκαταστήσει τις παρακάτω παλέτες (Manage Palette):
   - `@flowfuse/node-red-dashboard` (Dashboard 2.0)
   - `node-red-contrib-ui-led` (αν χρησιμοποίησες LED)

2. **Εισαγωγή (Import):**
   - Κατεβάστε το αρχείο `flows.json` από αυτό το repository.
   - Στο Node-RED, πηγαίνετε στο **Menu (πάνω δεξιά) -> Import**.
   - Επιλέξτε το αρχείο ή κάντε επικόλληση τον κώδικα JSON.

3. **Ρύθμιση MQTT:**
   - Κάντε διπλό κλικ στα `mqtt in` nodes και ρυθμίστε τη διεύθυνση του δικού σας Broker (π.χ. localhost ή τη IP του Raspberry Pi σας).

## 🛠 Hardware & Υλικά
- **ESP32** (Microcontroller με WiFi)
- **LM35** (Αισθητήρας θερμοκρασίας)
- **Κύκλωμα Ενίσχυσης:** Τελεστικός ενισχυτής (Op-Amp) με αντιστάσεις για βελτίωση της ακρίβειας του ADC.

## 📊 Χαρακτηριστικά (Features)
- **Live Dashboard:** Παρακολούθηση έως 4 ασθενών ταυτόχρονα.
- **Real-time Charts:** Ιστορικό θερμοκρασίας για κάθε αισθητήρα.
- **Smart Alerts:** Αυτόματη ειδοποίηση (Toast Notification) αν η θερμοκρασία ξεπεράσει τα όρια (36°C - 39°C).
- **Responsive Layout:** Σχεδιασμένο για να φαίνεται σωστά σε PC και Tablet.
